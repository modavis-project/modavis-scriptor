# Security

Version 0.1.0 is a local, single-user research application. Both published container ports bind to `127.0.0.1` by default. Reviewer names are self-asserted and are not authenticated.

Do not expose either service directly to an untrusted network. A network deployment requires authentication, authorization, transport security, upload scanning, request quotas and operational monitoring. Report vulnerabilities privately to the repository owner; do not attach credentials or confidential research images to an issue.
